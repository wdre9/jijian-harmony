# 更新日志 · Changelog

本文件记录「计件 · Jijian (HarmonyOS NEXT)」各版本的变更内容（中英双语）。

## [0.1.0] - 2026-10-10

### 新增 · Added

- HarmonyOS NEXT 原生工程：标准 Stage 模型，DevEco Studio 26（API 26），bundleName `com.wdre9.jijian`，应用名「计件」。
  Native HarmonyOS NEXT project: standard Stage model, DevEco Studio 26 (API 26), bundleName `com.wdre9.jijian`, app name "Jijian".
- 功能对齐 Android 版 jijian-app 首版：记账/明细/统计/我的四大 Tab、产品工序管理、工人管理、记录详情、数据导出、批量导入、关于页。
  Feature parity with the first release of Android jijian-app: four tabs (Entry / Details / Stats / Mine), product & process management, worker management, record details, data export, batch import, about page.
- 数据层使用 `@ohos.data.relationalStore` 建表实现单文档语义（products / processes / records / workers / settings / meta），内置 schemaVersion 迁移链。
  Data layer built on `@ohos.data.relationalStore` with single-document semantics (products / processes / records / workers / settings / meta) and a schemaVersion migration chain.
- OCR 本地识别：`@kit.CoreVisionKit` textRecognition，相册选图（PhotoViewPicker），数据不出本机。
  On-device OCR: CoreVisionKit textRecognition with album photo picking (PhotoViewPicker); data never leaves the device.
- 自动备份：保存数据后 24 小时节流，JSON 写入沙箱 `files/计件自动备份/`，滚动保留最近 14 份。
  Auto backup: 24-hour throttle after saving, JSON written to sandbox `files/计件自动备份/`, rolling keep of latest 14 backups.
- 手动导出：CSV（带 BOM）/ Excel（手写 SpreadsheetML 2003 XML，.xls）/ JSON / 文本；统计长图经 componentSnapshot 保存到图库。
  Manual export: CSV (with BOM) / Excel (hand-written SpreadsheetML 2003 XML, .xls) / JSON / text; stats snapshot saved via componentSnapshot.
- 图表：ArkUI Canvas 自绘 LineChart（趋势折线）、BarChart（工序/工人排行柱状）、PieChart（产品占比饼图）。
  Charts: custom Canvas components — LineChart (trend), BarChart (process/worker rankings), PieChart (product share).
- 主题：浅色 / 深色 / 跟随系统（监听系统深浅色自动切换）。
  Themes: light / dark / follow system (auto switch by system dark mode).
- 图标：Python(PIL) 生成 512×512 蓝底白字「计」图标，含分层 foreground/background。
  Icon: 512×512 blue rounded square with white "计" glyph generated by Python (PIL), including layered foreground/background.
- CI：`.github/workflows/build-harmony.yml`（push main + tag v* + 手动触发），Secrets 齐全时签名构建，缺省构建未签名 HAP 并在 Release 标注。
  CI: `.github/workflows/build-harmony.yml` (push main + tag v* + manual), signed build when Secrets present, unsigned HAP with release note otherwise.
- 文档：中英双文 README.md / CHANGELOG.md，与 Android 版文档风格一致。
  Docs: bilingual README.md / CHANGELOG.md in the same style as the Android version.
- 备份文件与 Android 版互导兼容：备份包 `app` 字段固定为 `jijian-pwa`。
  Backup files are interchangeable with the Android version: backup package `app` field is fixed to `jijian-pwa`.

### 技术说明 · Technical Notes

- 纯 ArkTS 实现：禁用 `any` / `unknown`，结构化类型用 `class` / `interface`，JSON 解析用 `JSON.parse` + 类型断言辅助。
  Pure ArkTS: no `any` / `unknown`; structured types via `class` / `interface`; JSON parsed with `JSON.parse` plus type assertions.
- 存储为单文档：逻辑上把全部业务数据视为一份 DataDoc，写入 RelationalStore 各表并带事务，后续升级可走迁移链。
  Single-document storage: all business data logically forms one DataDoc, written to RelationalStore tables in transactions, with a migration chain for future upgrades.
- UI 偏好存 `@ohos.data.preferences`：主题、默认工人、记住上次、首页范围、每日/每月目标。
  UI preferences stored in `@ohos.data.preferences`: theme, default worker, remember-last, home range, daily/monthly goals.

### 整改 · Rework (2026-10-12)

- 权限合规：统计长图保存由 `WRITE_IMAGEVIDEO` 动态权限改为 `SaveButton` 安全控件（组件级授权），移除 `module.json5` 权限声明及孤儿文案资源。
  Compliance: stats snapshot saving switched from `WRITE_IMAGEVIDEO` runtime permission to the `SaveButton` security component (component-level authorization); removed the permission declaration and orphan string resources.
- 类型安全：JSON 反序列化数据（迁移 / 备份导入 / 快照）改为逐字段类型守卫与手写递归深拷贝，替代 `JSON.parse` + 类型断言。
  Type safety: JSON-deserialized data (migration / backup import / snapshot) now uses field-level type guards and a handwritten recursive deep clone instead of `JSON.parse` + type assertions.
- 设备适配：`deviceTypes` 扩展为 `["phone", "tablet"]`（编译级支持；平板布局优化留待后续版本）。
  Devices: `deviceTypes` extended to `["phone", "tablet"]` (compile-level support; tablet layout optimization deferred to a later release).

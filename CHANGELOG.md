# 更新日志 · Changelog

本文件记录「计件通 · Jijian (HarmonyOS NEXT)」各版本的变更内容（中英双语）。

## [0.1.1] - 2026-10-19

### 新增 · Added

- 集成 AGC 隐私托管（AppGallery Kit 隐私管理服务）：首次启动经 `requestAppPrivacyConsent` 展示托管隐私政策/用户协议，同意后进入应用；已同意用户经 `getAppPrivacyResult` 直接进入；不同意一律退出（`terminateSelf`）。
  Integrated AGC hosted privacy consent (AppGallery Kit): first launch prompts via `requestAppPrivacyConsent` with hosted privacy policy / user agreement; already-consented users enter directly via `getAppPrivacyResult`; refusal always exits (`terminateSelf`).
- 上架合规：隐私政策/用户协议托管链接配置于 AGC（agreementId=2063176678921788096），module.json5 声明 `appgallery_privacy_hosted` 元数据。
  Store compliance: privacy policy / user agreement hosted on AGC (agreementId=2063176678921788096), `appgallery_privacy_hosted` metadata declared in module.json5.

### 修复 · Fixed

- 应用名称统一为「计件通」：AppScope 与 entry 三处 string.json（base / en_US）`app_name` 对齐，消除「提交名与终端显示名不一致」审核打回。
  App name unified to "计件通": all three `app_name` entries in AppScope & entry string.json (base / en_US) aligned, resolving the review rejection caused by name mismatch between submission and on-device display.
- 启动卡图标：EntryAbility 将 `loadContent` 与隐私确认解耦（onWindowStageCreate 立即加载），隐私流程加 5 秒超时兜底 + settled 互斥，杜绝启动窗口停留在图标导致「只显示一个图标」。
  Startup stuck on icon: EntryAbility decouples `loadContent` from privacy consent (loaded immediately in onWindowStageCreate), adds a 5-second timeout fallback with a `settled` mutual-exclusion guard, fixing the "only icon shown" startup hang.
- 隐私拒绝空结果误降级：拒绝返回空数组不再被吞成降级初始化，统一「未同意一律退出」。
  Empty-result consent regression: empty `results` from a refusal no longer falls through to degraded init; any non-agreed outcome exits the app.
- 主题递归闪退：`applyThemeToWindow` 按 `lastAppliedColorMode` 去重，切断 `setColorMode` 递归导致栈溢出闪退。
  Theme recursion crash: `applyThemeToWindow` deduplicates via `lastAppliedColorMode`, breaking the `setColorMode` recursion that caused stack-overflow crashes.
- 首页范围切换闪退：`homeRange` 改走 PrefStore 轻量存取并立即生效，消除切换瞬间退出/闪退。
  Home range switch crash: `homeRange` now uses PrefStore with immediate effect, eliminating the exit/crash on switch.

### 变更 · Changed

- 图标更新为 1024×1024 full-bleed 无文字原创设计（app_icon / icon / startIcon 三入口同源一致）。
  Icon updated to a full-bleed 1024×1024 text-free original design (app_icon / icon / startIcon all sourced identically).
- 功能对齐 Android 版补强：次数模式、工序三态（启用/禁用/删除隔离）、工序快照、日均口径、导出范围、导出次数语义与件次取整。
  Feature alignment with Android: count mode, process tri-state, process snapshots, daily-average semantics, export scope, export-count semantics and whole-unit rounding.
- CI 升级为 App Pack 链路：`assembleApp --mode project -p buildMode=release` 产出 .app，签名改为官方 `hap-sign-tool.jar` 离线签名（规避 hvigor SignHap 的 AES-GCM 密文密码限制）。
  CI upgraded to App Pack pipeline: `assembleApp --mode project -p buildMode=release` produces .app; signing switched to official `hap-sign-tool.jar` offline signing (bypassing hvigor SignHap's AES-GCM cipher-text password limitation).

## [0.1.0] - 2026-10-10

### 新增 · Added

- HarmonyOS NEXT 原生工程：标准 Stage 模型，DevEco Studio 26（API 26），bundleName `com.wdre9.jijian`，应用名「计件」。
  Native HarmonyOS NEXT project: standard Stage model, DevEco Studio 26 (API 26), bundleName `com.wdre9.jijian`, app name "Jijian".
- 功能对齐 Android 版 jijian-app 首版：记账/明细/统计/我的四大 Tab、产品工序管理、工人管理、记录详情、数据导出、批量导入、关于页。
  Feature parity with the first release of Android jijian-app: four tabs (Entry / Details / Stats / Mine), product & process management, worker management, record details, data export, batch import, about page.
- 数据层使用 `@ohos.data.relationalStore` 建表实现单文档语义（products / processes / records / workers / settings / meta），内置 schemaVersion 迁移链。
  Data layer built on `@ohos.data.relationalStore` with single-document semantics (products / processes / records / workers / settings / meta) and a schemaVersion migration chain.
- OCR 本地识别：`@kit.CoreVisionKit` textRecognition，相册选图（PhotoViewPicker），数据不出本机。
  On-device OCR: CoreVisionKit textRecognition with album photo picking (PhotoViewPicker); data never leaves the device.
- 自动备份：保存数据后 24 小时节流，JSON 写入沙箱 `files/计件自动备份/`，滚动保留最近 14 份。
  Auto backup: 24-hour throttle after saving, JSON written to sandbox `files/计件自动备份/`, rolling keep of latest 14 backups.
- 手动导出：CSV（带 BOM）/ Excel（手写 SpreadsheetML 2003 XML，.xls）/ JSON / 文本；统计长图经 componentSnapshot 保存到图库。
  Manual export: CSV (with BOM) / Excel (hand-written SpreadsheetML 2003 XML, .xls) / JSON / text; stats snapshot saved via componentSnapshot.
- 图表：ArkUI Canvas 自绘 LineChart（趋势折线）、BarChart（工序/工人排行柱状）、PieChart（产品占比饼图）。
  Charts: custom Canvas components — LineChart (trend), BarChart (process/worker rankings), PieChart (product share).
- 主题：浅色 / 深色 / 跟随系统（监听系统深浅色自动切换）。
  Themes: light / dark / follow system (auto switch by system dark mode).
- 图标：Python(PIL) 生成 512×512 蓝底白字「计」图标，含分层 foreground/background。
  Icon: 512×512 blue rounded square with white "计" glyph generated by Python (PIL), including layered foreground/background.
- CI：`.github/workflows/build-harmony.yml`（push main + tag v* + 手动触发），Secrets 齐全时签名构建，缺省构建未签名 HAP 并在 Release 标注。
  CI: `.github/workflows/build-harmony.yml` (push main + tag v* + manual), signed build when Secrets present, unsigned HAP with release note otherwise.
- 文档：中英双文 README.md / CHANGELOG.md，与 Android 版文档风格一致。
  Docs: bilingual README.md / CHANGELOG.md in the same style as the Android version.
- 备份文件与 Android 版互导兼容：备份包 `app` 字段固定为 `jijian-pwa`。
  Backup files are interchangeable with the Android version: backup package `app` field is fixed to `jijian-pwa`.

### 技术说明 · Technical Notes

- 纯 ArkTS 实现：禁用 `any` / `unknown`，结构化类型用 `class` / `interface`，JSON 解析用逐字段类型守卫 + 手写递归深拷贝（替代 `JSON.parse` + 类型断言）。
  Pure ArkTS: no `any` / `unknown`; structured types via `class` / `interface`; JSON parsed with field-level type guards and a handwritten recursive deep clone (no `JSON.parse` type assertions).
- 存储为单文档：逻辑上把全部业务数据视为一份 DataDoc，写入 RelationalStore 各表并带事务，后续升级可走迁移链。
  Single-document storage: all business data logically forms one DataDoc, written to RelationalStore tables in transactions, with a migration chain for future upgrades.
- UI 偏好存 `@ohos.data.preferences`：主题、默认工人、记住上次、首页范围、每日/每月目标。
  UI preferences stored in `@ohos.data.preferences`: theme, default worker, remember-last, home range, daily/monthly goals.

### 整改 · Rework (2026-10-12)

- 文档修正：README 中英双语「拍照 / from photos」改为「相册选图 / album photos」，与实际 `PhotoViewPicker` 实现对齐。
  Docs: README wording fixed from "photo-taking" to "album picking" (EN+CN), aligning with the actual `PhotoViewPicker` implementation.
- 权限合规：统计长图保存由 `WRITE_IMAGEVIDEO` 动态权限改为 `SaveButton` 安全控件（组件级授权），移除 `module.json5` 权限声明及孤儿文案资源；同步清理 Database / PrefStore 冗余 `BusinessError` import 与 StatsPage 的 `getContext as` 向下转型；不依赖受限权限 `CUSTOMIZE_SAVE_BUTTON`，按钮文案用系统预设（DOWNLOAD）。
  Compliance: stats snapshot saving switched from `WRITE_IMAGEVIDEO` runtime permission to the `SaveButton` security component (component-level authorization); removed the permission declaration, orphan string resources, and redundant `BusinessError` imports; dropped the `getContext as` downcast in StatsPage; no reliance on restricted `CUSTOMIZE_SAVE_BUTTON` — button text uses the system preset (DOWNLOAD).
- 类型安全：不安全类型断言（`as`）全部消除——JSON 反序列化（迁移 / 备份导入 / 快照）改为逐字段类型守卫（migrateDoc / parseBackupPackage）与手写递归深拷贝，`doc as object` 等向下转型一并消除。
  Type safety: all unsafe `as` assertions eliminated — JSON-deserialized data (migration / backup import / snapshot) now uses field-level type guards (migrateDoc / parseBackupPackage) and a handwritten recursive deep clone; `doc as object` downcasts removed too.
- 设备适配：`deviceTypes` 扩展为 `["phone", "tablet"]`（编译级支持；平板布局优化留待后续版本）。
  Devices: `deviceTypes` extended to `["phone", "tablet"]` (compile-level support; tablet layout optimization deferred to a later release).
